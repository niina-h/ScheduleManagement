# 実績入力画面でタスクの状態を変更できます

実績入力画面から、ガントチャートのタスクの状態をその場で変更できるようになりました。

---

## 1. 何ができるようになったか

- 実績入力画面の各行で、**タスクの状態（未着手・着手・順調・遅れ・完了・中断）** を選べます
- 選んだ時点で**自動的に保存**されます（「保存」ボタンは不要）
- 「遅れ」を選ぶと、**遅れ日数（0〜10日）** も指定できます
- 状態と実績が食い違っていると、**⚠警告**が出て気付かせます

---

## 2. どこと連動するか

変更した状態は、**ガントチャート**に直接反映されます。

```
実績入力画面            ガントチャート
 状態を選ぶ    ───→    状態・進捗バーが
                        その場で変わる
```

### 連動するもの

- **ガントチャートの状態**
  - 実績入力で選んだ状態が、そのままガントチャートの状態になります
- **ガントチャートの進捗バー**
  - 「遅れ」の日数を選ぶと、その分だけバーが戻ります

### 連動しないもの

- **過去の実績データ**
  - 状態を変えても、過去に入力した実績は一切変わりません
- **実績の時間・作業名**
  - これらは従来どおり「保存」ボタンが必要です

> **ご注意**：過去の日付を開いているときに状態を変更しても、変わるのは**タスクの「今」の状態**です。その日の状態が記録されるわけではありません。

---

## 3. 状態の選択が出ない行があります

状態の選択は、**ガントチャートに登録されているタスクに紐付いた行だけ**に表示されます。

- 朝礼・掃除・問い合わせ対応などの**定例業務**
- 会議・打合せなどの**イベント**
- ガントチャートに**登録していない作業**
- すでに**「完了」「中断」にしたタスク**

変更する先（ガントチャートのタスク）が存在しないためで、不具合ではありません。作業名の左にある 🔗 が青ければ紐付いており、灰色の — なら紐付いていません。

---

## 4. 変更できる人

- そのタスクの**担当者本人**
- **管理職以上**（管理職・所属長・システム管理者）
