## v1.11.0 リリース内容詳細（2026-05-18）

### 日報メール / Outlook 連携
- 「Outlookで開く」を mailto: 方式へ戻し、クリック時に Outlook 起動確認ダイアログを表示。未起動時は起動依頼メッセージを案内
- マスタ用メール挨拶テンプレートから「様」を削除（役職と二重敬称になっていたため）
- マスタ用メール本文：当日以前に完了したタスクは「業務内容」セクションから除外
- マスタ用メール本文：メンバーの当日休暇（1日有休／AM半休／PM半休／特休／祝日／その他休み）を AM/PM サマリに反映
- 「次回予定」のロジックを土日のみスキップから「土日 + 会社休日 + 本人の全休休暇」をスキップする共通関数 `get_next_business_day` に統一（日報メール・Excel・印刷HTML 5箇所）

### 週間予定
- 火曜以降に翌日予定を変更した際に月曜日のデータが消える事象を修正（過去日 disabled でフォーム送信されない問題を save 側で除外処理）
- タスク管理反映を「上書き再配置」仕様に変更：既存の取込タスクを一旦クリアし、新規ID降順で再配置
- 取込・先週コピーで休日設定（会社休日・本人の全休休暇）の日をスキップ
- 取込対象タスクと同名の手動入力スロットも再配置候補に含める（配置順末尾のタスクが反映されない事象の根本対応）

### タスク管理 / ガントチャート
- 担当者ごとの「📅 予定反映」チェックボックスを追加（`import_to_schedule_1` / `import_to_schedule_2` カラム）。担当者単位でタスク管理反映の対象を制御
- タスク一覧に **期間絞り込み + 今週 / 次週 / クリアボタン** を追加（デフォルトは空白＝全範囲）
- タスク管理画面の絞り込み状態（中区分・担当者・期間）をガントチャート遷移時に引き継ぎ
- ガントチャート画面でも中区分・期間・マスタ用ユーザー切替プルダウンを追加。Excel 出力にも全フィルタを反映
- ガントチャート行ドラッグ並び替えの保存堅牢化（ドラッグ領域を 20px → タスク名+担当者列の 270px に拡張、`display_order` 衝突回避ロジック、fetch エラー詳細表示）
- ガントチャート Excel 出力の階層構造を画面と統一（大区分→中区分→タスクの3階層）
- タスク追加後の連続入力対応：大区分・中区分・担当者・期間・状態・反映チェックは保持、タスク名/対応内容/進捗のみクリアして即フォーカス
- 定例作業削除後のタブ位置を維持（`?tab=routine` 付与）

### 通知 / その他
- イベント開始10分前の Windows 通知（ブラウザ Notification API）。社内 LAN 完結・外部通信なし。`setTimeout` ベースで正確な10分前発火、`/api/today-events` で当日分を取得し5分ごとに再予約
- 管理ダッシュボード「メンバー全員エクスポート」で他部署のユーザーが混入する不具合を修正
- マスタ権限が他のマスタ・自分以外の全ユーザーにアクセス可能に（`can_access_user`）
- 管理職／マスタが自分自身の画面でも上長コメントを読み取り専用で参照可能に
- run_production.py にファイルログ機能を追加（`logs/server.log`、5MB×5世代でローテーション）
