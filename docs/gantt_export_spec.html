技術仕様書 — 帳票出力（Excel / PDF）共通基盤

格子状レポートを Excel と PDF で同一レイアウト出力する仕組み

ガントチャートの Excel／PDF ダウンロード機能で用いた実装方式を、他システムへ再利用できるよう技術仕様としてまとめたものです。「表＋日付グリッド＋バー」のような格子状レポートを、openpyxl（Excel）と reportlab（PDF）で見た目を揃えて出力します。

01方式の概要と重要な前提

本方式は 「Excel ファイルを PDF に変換する」ものではありません。同じデータ・同じレイアウト定義から、Excel と PDF をそれぞれ独立に描画します。両者は「見た目が一致する」ように作り込みますが、内部的には別のライブラリで別々に生成されます。

INPUT
共通データ
表示対象の行データ（ツリー/リスト）＋期間・列定義
PATH A
openpyxl
セル・罫線・塗りで Excel を組み立て
PATH B
reportlab
canvas に矩形・文字・線を描いて PDF 化
OUTPUT
ダウンロード
Flask send_file でブラウザへ配信
設計の要点：「行データを平坦化したリスト」と「列定義（ラベルと幅）」を共通の入力とし、Excel 版・PDF 版の描画関数がそれぞれ同じ入力を受け取る構成にします。これにより両出力のレイアウトが自然に一致し、片方だけ崩れる事故を防げます。

03Excel 生成（openpyxl）

セル単位でスタイルを設定します。塗り・罫線・整列・列幅・結合・印刷設定が要点です。

import openpyxl
from openpyxl.styles import Font, PatternFill, Border, Side, Alignment
from openpyxl.utils import get_column_letter

wb = openpyxl.Workbook(); ws = wb.active
ws.title = "ガントチャート"

# スタイル部品
thin = Border(left=Side(style="thin", color="CCCCCC"), right=Side(style="thin", color="CCCCCC"))
header_fill = PatternFill("solid", fgColor="334155")   # 16進カラー
center = Alignment(horizontal="center", vertical="center")

# セルに値・スタイルを設定
cell = ws.cell(row, col, "値")
cell.fill = header_fill
cell.font = Font(bold=True, color="FFFFFF", size=9, name="游ゴシック")
cell.alignment = center
cell.border = thin

# 列幅・セル結合
ws.column_dimensions[get_column_letter(col)].width = 3.5
ws.merge_cells(start_row=r, start_column=1, end_row=r, end_column=10)

# 印刷設定（A4横・幅1ページに収める）
ws.page_setup.orientation = "landscape"
ws.page_setup.fitToWidth = 1
ws.page_setup.paperSize = ws.PAPERSIZE_A4
ws.freeze_panes = "F3"   # 固定列・見出しの固定

日付列のセルを、期間・進捗に応じて塗り分けます。1セル＝1日。

if t_start <= dt <= t_end:                # その日がタスク期間内なら

04PDF 生成（reportlab）

reportlab の canvas に、矩形・文字・線を直接描きます。表もバーも「塗った矩形」の組み合わせで表現するため、Excel と同じ絵を再現できます。

4-1. 初期化と日本語フォント

import io
from reportlab.lib.pagesizes import A4, landscape
from reportlab.pdfgen import canvas as _canvas
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.cidfonts import UnicodeCIDFont

# 日本語CIDフォント登録（フォントファイル不要・reportlab同梱）
pdfmetrics.registerFont(UnicodeCIDFont("HeiseiKakuGo-W5"))
jp_font = "HeiseiKakuGo-W5"

# 16進カラー → reportlabのRGB(0〜1)へ変換
def _rgb(h): return (int(h[0:2],16)/255, int(h[2:4],16)/255, int(h[4:6],16)/255)

buf = io.BytesIO()
c = _canvas.Canvas(buf, pagesize=landscape(A4))
page_w, page_h = landscape(A4)
座標系の注意（最重要）：reportlab は左下が原点で、Y は上に向かって増加します。Excel やブラウザ（左上原点・下方向が増加）と上下が逆です。行を上から並べるときは y = page_h - margin - ... と計算し、次の行へは y -= row_h（減算）で下げます。

4-2. 表・グリッド・バーの描画プリミティブ

# セルを塗る（塗りつぶし矩形）  rect(左下x, 左下y, 幅, 高さ)
c.setFillColorRGB(*_rgb("334155"))
c.rect(x, y, w, h, fill=1, stroke=0)

# 文字（中央/左/右寄せ）
c.setFillColorRGB(1, 1, 1)
c.setFont(jp_font, 7)
c.drawCentredString(x + w/2, y + 4, "文字")
c.drawString(x + 2, y + 4, "文字")
c.drawRightString(x, y, "文字")

# 罫線・枠
c.setStrokeColorRGB(*_rgb("CCCCCC")); c.setLineWidth(0.4)
c.line(x1, y1, x2, y2)
c.rect(x, y, w, h, fill=0, stroke=1)     # 枠だけ

# バー（Excelと同じ色分けロジック）
c.setFillColorRGB(*_rgb(fill))
c.rect(cx + 0.5, y + 2, day_w - 1, row_h - 4, fill=1, stroke=0)

4-3. 複数ページ（行数でページ送り）

margin = 14; row_h = 15; header_h = 26
rows_per_page = int((page_h - margin*2 - header_h) // row_h)

idx = 0
while idx < len(rows):
    _draw_header(...)                # 各ページ先頭に見出しを描く
    y = page_h - margin - header_h - row_h
    drawn = 0
    while idx < len(rows) and drawn < rows_per_page:
        _draw_row(rows[idx], y)       # 1行描画
        y -= row_h; idx += 1; drawn += 1  # 座標系が下向き増加なので減算
    c.showPage()                    # ← 改ページ確定

c.save()
buf.seek(0)                          # BytesIO を返す

05Flask での配信

生成した BytesIO を send_file で返すだけです。Excel と PDF で mimetype と拡張子が違うのみ。

from flask import send_file

# Excel
return send_file(buf, as_attachment=True,
    download_name="レポート.xlsx",
    mimetype="application/vnd.openxmlformats-officedocument.spreadsheetml.sheet")

# PDF
return send_file(buf, as_attachment=True,
    download_name="レポート.pdf", mimetype="application/pdf")

06他システムへの移植手順

  • 1. 依存を追加：pip install openpyxl reportlab
  • 2. 共通入力を定義：描画対象を「行データのリスト」に平坦化する。ツリー構造なら再帰で親→子の順に並べ、各行に type（見出し/データ）・表示値・期間・進捗を持たせる。
  • 3. 列定義を1箇所に：[(ラベル, 幅), ...] の形で固定列を定義し、Excel/PDF 両方でこの定義を使う。
  • 4. 描画関数を2つ用意：build_xlsx(rows, cols, ...) と build_pdf(rows, cols, ...)。本仕様の 03／04 のプリミティブをコピーして中身を実装。
  • 5. 配信ルートを2本：それぞれ send_file で返す（05）。
  • 6. 色・フォントの共通化：色は16進文字列で一元管理し、Excel は PatternFill(fgColor=...)、PDF は _rgb(...) に渡すと一致する。
再利用のコツ：「行の平坦化」と「列定義」さえ共通化すれば、レポートの種類（ガント／勤怠表／集計表）が変わっても、描画プリミティブ（矩形・文字・線）はそのまま流用できます。表形式の帳票なら本方式がそのまま適用可能です。

07代替方式（本物の Excel→PDF 変換が必要な場合）

本方式は「同じ絵を2回描く」再描画方式です。既存の Excel ファイルをそのまま PDF 化したい場合は別手段が必要です。

方式手段長所短所
再描画（本仕様）reportlabExcel不要・レイアウト完全制御・サーバー完結描画コードが必要
Excel→PDF変換LibreOffice
soffice --convert-to pdf		既存Excelをそのまま変換LibreOffice の導入が必要
Excel→PDF変換Excel COM
win32com		Excel本体の描画そのままExcel必須・Windows限定・サーバー不向き

格子状の帳票（表＋グリッド＋バー）を安定してサーバー生成するなら、本仕様の再描画方式（reportlab）を推奨します。レイアウトが複雑でも外部プロセスに依存せず完結します。
