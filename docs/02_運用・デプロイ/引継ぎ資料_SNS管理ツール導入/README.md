# 引継ぎ資料 — SNS管理ツール運用

同一端末では予定管理システムも稼働しており、両システムはポート・タスク名・配置フォルダが分離されている。

## ★ 2026-09-28 改訂の要点

初版は「これから新規リリースする」前提で作成したが、実機調査の結果、**SNS管理ツールは既に本番配置・稼働済み**であることが判明した。
本改訂で以下を実態に合わせて訂正している。

| 項目 | 初版の記載（誤） | 実態（正） |
|------|-----------------|-----------|
| 予定管理システムの本番配置 | `C:\DEV\ScheduleManagement\` | **`C:\App\ScheduleManagement\`** |
| SNS管理ツールの状態 | 未配置・これからリリース | **`C:\App\SnsManagementTool\` に配置済み・稼働中** |
| SNS管理ツールの実装 | Flask 等（未確定） | **Streamlit アプリ** |
| タスク登録 | これから登録 | **`SnsManagementServer` 登録済み・BootTrigger 有効** |

`C:\DEV\ScheduleManagement\` は開発用の作業フォルダであり、本番ではない。

## 使い方

### 引継ぎを受ける担当者

1. **04_本番PCシステム概要図.html** で2システムの同居構成を把握
2. **05_SNS管理ツール運用手順.md** で日常の更新・再起動手順を把握
3. **03_リリース後メンテナンス〜.html** でバックアップ・月次点検のルールを把握

### 更新作業をするとき

1. **05_SNS管理ツール運用手順.md** の手順に従う
2. Claude Code に依頼する場合は **01_リリース指示書.md** の §1 テンプレートを使う

## 注意事項

- **予定管理システム（ポート5000 / `ScheduleServer`）を絶対に止めないこと。** 業務時間中は利用者が接続している。
- SNS管理ツールは **Git 未使用**。NAS のバージョンフォルダとローカルバックアップが履歴の全て。
- バックアップ時は **`.venv` を必ず除外**する（環境依存・容量肥大）。
- 本番 Python は `C:\Python\Python313\python.exe` を両システムで共用している。**Python 本体の更新は両システムに影響する。**
- HTML版と Markdown版は同一内容。閲覧・印刷は HTML、Git 管理・AIツール連携は Markdown を使用。
