## 使い方

### 引継ぎ先担当者が最初に読む

1. **02_一般的なリリース手順書.html** — ブラウザで開く。リリース作業全体の流れを把握。
2. **03_リリース後メンテナンスとバージョン管理規定.html** — リリース後の運用・バージョン管理ルールを把握。

### 実際にリリース作業をするとき

3. **01_ClaudeCode向け_SNS管理ツール_リリース指示書.md** — Claude Code に本ファイルの「§1 指示テンプレート」をコピーして渡す。

## 注意事項

- SNS管理ツールは **Git 未使用**。フォルダバックアップがバージョン履歴の唯一の記録なので、命名規則を厳守すること（§04 参照）。
- 既存の予定管理システム（ポート5000／タスク名 ScheduleServer）を **絶対に止めないこと**。SNS管理ツールは別ポート・別タスク名で共存させる。
- HTML版と Markdown版は同一内容。閲覧・印刷は HTML、Git 管理・AIツール連携は Markdown を使用。
