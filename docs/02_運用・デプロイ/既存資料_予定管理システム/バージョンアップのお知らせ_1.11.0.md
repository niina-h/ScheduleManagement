# 予定管理システム バージョンアップのお知らせ（v1.11.0）

## リリース日
2026-07-27

## 主な変更内容

### ガントチャートが新方式になりました
- タスクを「親子ツリー」構造で管理できるようになりました（最大4階層：親・子・孫・曾孫）。
- 親タスクのバーを動かすと、配下の子タスクも同じ日数分まとめて移動します。
- タスク詳細画面から「ガントバーを削除」して日程未設定に戻せるようになりました。
- 操作を間違えたときは **Ctrl+Z**（または「↩ 元に戻す」ボタン）で1つ前の状態に戻せます。
- Excel／PDF出力に対応しています。

### 初回ログイン時にアンケートが表示されます
- 「使いやすさ」「メリット」「デメリット」「希望機能」「他部署・他社への推奨」の5問です。
- **1人1回だけ**表示されます。回答すると次回からは表示されません。

### その他
- 役職体系が4段階（システム管理者／所属長／管理職／一般）になりました。
- ログイン方法が「ログインID＋4桁パスワード」方式になりました。

## ユーザーに必要な作業

1. **初回ログイン時にアンケートに回答してください**（1回だけ・スキップ不可）。
2. ログイン画面が変わっている場合は、管理者から案内されたログインID・パスワードでログインしてください。
3. ガントチャートを使う方は、操作を間違えたら焦らず **Ctrl+Z** で戻せることを覚えておいてください。
4. 不明な点があれば画面右上のヘルプ（❓）から確認できます。

## 管理者に必要な作業

- 特別な設定作業は不要です。リリース後、通常通りログインして動作をご確認ください。
- 「アンケート回答一覧」画面（管理者ダッシュボードから）で、メンバーの回答状況を確認できます。
