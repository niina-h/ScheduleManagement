▶ 使い方 {% if page == 'routine' %}
  1. 「＋ 定例追加」で作業名・時間・頻度を指定して登録します。頻度は日次（曜日ごと・区分あたり最大3件）、週次（日付指定）（特定1日のみ）、週次（第何週＋曜日）（例：第2・第4水曜日）、年次（毎年同じ月日）の4種類です。
  2. 区分（午前／午後）を選ぶと、週間予定への反映時にその時間帯の空きスロットへ自動配置されます。
  3. 一覧の「編集」ボタンで既存の定例を修正できます（頻度・区分の変更も可）。「✕」で削除。
  4. ここで登録した定例はガントチャートには表示されません（週間予定専用）。週間予定画面の「ガントチャート反映」実行時に、その日の頻度条件に合う定例が自動配置されます。
{% elif page == 'events' %}
  1. 「＋ イベント追加」で会議・行事などを登録します（全ユーザーが登録可能）。開始日・終了日・時刻・関係者（複数選択）を設定できます。
  2. 関係者に自分が含まれるイベントのみ編集できます（他者のイベントは閲覧のみ）。
  3. MSチェックを付けると、ガントチャート上でマイルストーン（縦線）として表示されます（バーは表示されません）。
  4. 「開催日が過ぎたものだけ表示」で終了済みイベントを絞り込めます。チェックボックスで選択して一括削除も可能です。
{% else %}
  1. 「＋ タスク追加」でタスクを登録します（大区分・中区分・タスク名・開始日・終了日は必須）。担当者1はログインユーザーが既定選択されます。
  2. ここで登録したタスクはガントチャート・進捗ダッシュボード・日報メールに反映されます。期間や担当者を変えたい場合はガントチャート画面から編集する方が親子関係も含めて分かりやすいです。
  3. 一覧の各行はインライン編集ができます（タスク名・日付・状態・進捗率など）。編集後は「一括保存」ボタンで反映してください。
  4. 中区分フィルター・完了表示チェックで絞り込みできます（絞り込み状態は保持されます）。
  5. 状態が「着手・順調」のタスクは、開始日・終了日から進捗率が自動計算されます（「遅れ」「中断」は入力値がそのまま使われます）。
  6. 今日時点の理想進捗より実際の進捗が下回っているタスクは、状態・進捗の文字が赤色で表示されます（ガントチャートと同じ遅延警告。完了・中断のタスクは対象外）。
{% endif %}
