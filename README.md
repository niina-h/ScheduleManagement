# ScheduleManagement — 予定管理システム

チームメンバーが週間・日次の作業予定と実績を登録・共有し、ガントチャートで案件の進捗を管理するための Web アプリケーションです。
ブラウザからアクセスでき、インストール不要で複数ユーザーが同時に利用できます。

---

## 機能概要

| 機能 | 説明 |
|------|------|
| ログイン | ログインID＋4桁PINでログイン。次回から自動ログインの記憶トークンに対応 |
| 週間予定入力 | 月〜金の午前・午後スロット（各5枠）に作業名と作業時間を登録する |
| 先週コピー／全クリア | ボタン1つで先週の予定をコピー、または対象週を一括クリアできる |
| ガントチャート反映 | ガントチャートに登録した案件・定例作業・イベントを週間予定へ自動配置する（当週は誤操作防止のため反映不可） |
| 日次実績管理 | 当日の作業実績を記録。リスケ（翌営業日への転記）・繰越に対応 |
| 振り返り（個人） | その日のガント予定と実績の差分を「前倒し／予定通り／遅れ」で自動判定・表示 |
| 振り返り（管理職・所属長向け） | 配下メンバー全員の当日の予定・実績差分を一覧できる新画面 |
| タスクマスター | よく使う作業名をユーザーごとに登録・管理し、予定入力時に選択できる |
| 定例作業 | 曜日ごとの定例作業を登録し、週間予定反映時に空きスロットへ自動的に詰め込む（詰め方向を上から／下からで選択可） |
| ガントチャート（視覚入力・新方式） | タイムライン上でバーをドラッグして描画し、親子ツリー構造でタスクを登録する |
| ガントチャート（旧方式） | フォーム入力でタスクを登録し、大区分・中区分でグルーピング表示する画面。当面は新方式と並存 |
| イベント管理 | 会議・行事などの単発イベントを月カレンダーから登録・一覧できる |
| データ移行（Excel） | 旧タスク一覧を新ガントチャート構造へ、Excel経由でエクスポート・インポートできる（システム管理者限定） |
| ブラビオ取込 | ブラビオExcelファイルからタスクを一括インポート |
| 全体ステータス／進捗ダッシュボード | プロジェクト全体・担当者別の進捗をグラフ・テーブルで俯瞰する |
| 管理者ダッシュボード | 全ユーザーの週間予定登録状況・当日実績状況を一覧で確認できる |
| ユーザー管理・所属管理 | 管理者がユーザーの追加・削除・所属（複数可）・基本勤務時間を管理する |
| 操作ログ | ログイン・データ保存・ユーザー操作などの操作履歴を記録・閲覧できる |
| メール日報 | 管理職・システム管理者・一般ユーザーそれぞれの日報メールをプレビュー・送信設定できる |
| Excel／PDF出力 | 週間予定・ガントチャート・日報を Excel／PDF でダウンロードできる |
| ヘルプ | アプリ内にヘルプ・手順書ページを内蔵。各機能の使い方を参照できる |

## 動作環境

- Python 3.9 以上
- Flask 3.0 以上
- openpyxl 3.1 以上

依存パッケージのインストール：

```bash
pip install -r requirements_web.txt
```

---

## 起動方法

```bash
python run_web.py
```

起動後、ブラウザで `http://localhost:5000` にアクセスしてください。

## 権限（4段階の役職体系）

| 役職 | 参照範囲 | できること |
|------|---------|-----------|
| 一般 | 自分のみ | 自分の週間予定・日次実績の入力・編集、タスクマスター管理、自分の担当タスク・イベントの編集、日報メールプレビュー |
| 管理職 | 自部署（直属部下） | 上記に加え、部下の登録状況確認・編集、振り返りレビュー、部下の予定・実績振り返り一覧、日報メール作成・送信設定、タスク管理・ガントチャート・進捗ダッシュボード |
| 所属長 | 担当所属（複数指定可） | 管理職と同等の権限を、割り当てられた所属のメンバーに対して行使する |
| システム管理者 | 全所属 | 全ユーザーの参照・管理、所属マスタ管理、操作ログ閲覧、パスワード設定、データ移行機能、全機能へのフルアクセス |

初期ユーザーは `data/users.json` に定義します。アプリ初回起動時に自動的にデータベースへ取り込まれます。
その後はブラウザの管理者ダッシュボードからユーザーを追加・削除できます。

## データファイル

| ファイル | 用途 | 備考 |
|----------|------|------|
| `data/users.json` | 初期ユーザーマスタ | 初回移行後は DB が正となる |
| `db/web_app.db` | 本番用アプリDB | 自動生成・自動更新 |
| `db/web_app_dev.db` | 開発用DB | `FLASK_ENV_LABEL=DEV` 環境変数で切替 |
| `output/` | Excel・その他出力ファイル | 手動管理 |
